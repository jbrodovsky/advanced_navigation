# Advanced Navigation

This repository now serves two roles:

- Quarto source for the course notes and assignments
- starter Python workspace for the major course projects

The starter code lives under `projects/`:

- `projects/drone_pipeline`
- `projects/victoria_park_slam`
- `projects/ins_gnss`

Each project package provides:

- dataset loading utilities
- typed records and configuration helpers
- plotting and diagnostic hooks
- public starter interfaces for the project algorithms

The assignment handouts in `book/assignments/` reference these packages directly so students can work from a consistent layout instead of building ad hoc notebooks and scripts from scratch.
